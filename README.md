# Integrated AI System: Expert System, Search Algorithm & Multi-Agent

Program ini adalah simulasi sistem AI terpadu untuk deteksi dan respon gangguan jaringan.

## 🚀 Fitur Utama
1. **Search Algorithm**: Menggunakan **Breadth-First Search (BFS)** untuk mencari rute cadangan terpendek pada topologi jaringan.
2. **Expert System**: Menggunakan metode **Forward Chaining** berbasis aturan (*if-then*) untuk mendiagnosis jenis masalah jaringan berdasarkan fakta.
3. **Multi-Agent System**:
   - `MonitoringAgent`: Mengumpulkan status dan fakta dari jaringan.
   - `ResponseAgent`: Menganalisis diagnosis dan mengambil tindakan perbaikan/rerouting.
